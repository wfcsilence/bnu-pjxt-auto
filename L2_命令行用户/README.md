# L2 · 命令行版

给会用命令行、不想依赖大模型的人。**Windows / macOS 各有一套**，文件互不通用。

## 先选平台

| 你的系统 | 进哪个文件夹 | 双击什么 |
|----------|-------------|---------|
| Windows 10 / 11 | `Windows/` | `一键评教.bat` |
| macOS | `macOS/` | `一键评教.command`（首次需 `chmod +x`） |

不确定的话：Windows 的文件夹里文件以 `.bat` 结尾，macOS 的以 `.command` 结尾。

## 两个平台里都有什么

| 文件 | 干什么 | 你要改吗 |
|------|--------|---------|
| `一键评教.bat` / `.command` | 双击入口，只负责找到 Python 并转交 | 不用 |
| `launcher.py` | 中文提示、检测端口、拉起浏览器、**逐项问你要填什么**、最后确认 | 不用 |
| `run.py` | 逐门循环：探测 → 点击 → 填写 → 提交 | 不用 |
| `engine.py` | CDP 引擎，纯标准库，零第三方依赖 | 不用 |
| `config.json` | 填写规则与默认值（`answer` 段）+ 站点地址 | 只在想改「回车默认值」时改 |
| `使用说明.md` | 平台专属操作步骤 + 故障排查 | — |

## 第一次用要做什么

1. 装 Python 3（Windows 安装时勾选 `Add python.exe to PATH`）
2. 双击入口文件
3. 在弹出的**专用浏览器窗口**里登录一次评教系统
4. 回到命令行，**逐项回答要填什么**（直接回车＝用默认值）
5. 看一遍预览，按 `Y` 回车开始

登录态存在独立配置目录里，**之后每次都不用再登录**，也不会影响你平时用的浏览器。

## 想改填写内容

**不用改文件**，运行时按提示输入就行：

- 选择题：输编号 `1`–`5`，或直接输「好」「较好」「一般」「较差」「差」
- 三个填空：需要改进的地方 / 突出优点 / 打分
- 直接回车 = 用括号里的默认值；填空想留空输 `-`

如果你希望「回车默认值」也换掉（比如你们班统一选「较好」），再改 `config.json` 的 `answer` 段：

```json
"answer": {
  "pick": "较好",
  "pick_options": ["好", "较好", "一般", "较差", "差"],
  "fills": [
    {"label": "需要改进的地方？", "default": "无"},
    {"label": "突出优点是什么？", "default": "无"},
    {"label": "打多少分？（满分100分）", "default": "95"}
  ]
}
```

      选哪一项？[1-5，回车=1 好]：2

      确认开始？输入 Y 回车开始，直接回车取消：Y

[4/4] 开始批量填写，期间请勿操作那个浏览器窗口...

填写方案：选择题「较好」；填空 无 / 多讲案例 / 95

iter0: 金梦 -> {'step': 'clicked', 'checked': 40, 'total': 40}

...
完成提交=9 跳过=1 剩余待办=0

- `[3/4]` 那一段是**最后核对机会**，看清再按 Y
- `checked: 40 / total: 40` = 8 道题 × 5 个选项全部选中，说明填写完整
- `跳过=1` = 有一门点进去发现已评过，自动跳过，正常
- `剩余待办=0` = 全部完成

## 出问题怎么办

| 现象 | 解决 |
|------|------|
| 一闪就消失 | 用记事本打开 bat 确认无乱码；新版应为纯英文提示 |
| 提示 Python 3 not found | 装 Python 并勾 PATH，或重启命令行窗口 |
| 30 秒端口未就绪 | 访问 `http://127.0.0.1:9222/json/version` 自查；关掉专用窗口重试 |
| 提示「没有登录态」 | 专用窗口里登录一次 |
| 数量不减少就停了 | 看页面是否报错；必要时重跑，已提交的会跳过 |
| 填错了想重来 | 提交后改不了；下一门重新输入即可，已提交的不会重复提交 |

更详细的分平台说明见各自文件夹里的 `使用说明.md`；引擎与配方的技术细节见上一层 `README.md` 的「给 Agent 的接口说明」。
