# Windows · 使用说明

## 你需要准备

- Windows 10 / 11
- Python 3：终端执行 `python --version` 能看到版本号即可
  - 没装的话去 https://www.python.org/downloads/ 下载，**安装第一步务必勾选 `Add python.exe to PATH`**
- Edge 或 Chrome（系统自带 Edge 就行）

## 第一次使用

1. **双击 `一键评教.bat`**
2. 脚本会说明要启动专用浏览器，按**回车**
3. 在弹出的窗口里**登录评教系统**（账号密码和平时一样），能看到课程列表就行
   - 这个窗口用独立配置目录，**和你平时用的 Edge 互不影响**
   - 登录态会保存下来，以后不用再登
4. 回到黑色命令行窗口，**逐项回答要填什么**（见下一节）
5. 看一眼预览，输入 **`Y`** 回车
6. 脚本自动逐门处理，**期间不要动那个浏览器窗口**
7. 跑完去浏览器「已评教」标签核对

> 如果你的系统是英文/其他语言，中文提示依然正常显示——bat 是纯 ASCII，中文由 Python 输出并自行切换控制台编码。

## 命令行会问你什么

按提示输入即可，冒号后面就是你要敲的内容。样例（假设选「较好」、优点写「多讲案例」、打 95 分）：

```text
[2/4] 请设定要填写的内容（直接回车 = 用方括号里的默认值）

      选择题（1)好   2)较好   3)一般   4)较差   5)差）
      选哪一项？[1-5，回车=1 好]：2

      填空题共 3 项（按页面上的顺序）：
       1. 需要改进的地方？ [回车=无]：
       2. 突出优点是什么？ [回车=无]：多讲案例
       3. 打多少分？（满分100分） [回车=90]：95

[3/4] 将要提交的内容

      选择题：每题都选「较好」
      需要改进的地方？ 无
      突出优点是什么？ 多讲案例
      打多少分？（满分100分） 95

      评教一经提交无法修改，请再核对一遍。

      确认开始？输入 Y 回车开始，直接回车取消：Y
```

输入规则：

| 你想做的 | 怎么输 |
|---------|--------|
| 选某个选项 | 输编号 `1`–`5`，或直接输「好」「较好」「一般」「较差」「差」 |
| 用默认值 | 直接回车 |
| 填空留空 | 输一个 `-` |
| 改主意取消 | 在最后「确认开始」那一步直接回车 |
| 输错了 | 选择题会重问（最多 3 次，之后用默认）；填空只能重跑一次 |

两个细节：

- 全角数字（`９５`）会自动转成半角（`95`），中文输入法下不用切键盘。
- 分数超出 0–100 或不是数字时，只**提醒**不拦你，自己确认即可。

## 以后使用

直接双击 `一键评教.bat`。端口还开着就跳过启动步骤，仍然会问内容并要你确认。

专用窗口被关掉了也没关系，再双击会自动重新拉起，登录态还在。

## 常用操作

| 想做的事 | 怎么做 |
|---------|--------|
| 改这次填的内容 | 运行时按提示输入，**不用改任何文件** |
| 改「回车默认值」 | 记事本打开 `config.json`，改 `answer` 段里的 `pick` 和 `fills` |
| 查看端口是否就绪 | 浏览器打开 `http://127.0.0.1:9222/json/version`，有 JSON 就是正常的 |
| 关掉专用浏览器 | 直接关窗口即可，不影响登录态 |
| 更换评教地址 | 改 `config.json` 的 `list_url` |

## 故障排查

| 现象 | 原因 / 解决 |
|------|------------|
| 双击后窗口一闪消失 | 用记事本打开 bat，新版应该是**纯英文**提示。若是中文乱码，说明拿到了旧版本，换成新的 |
| `Python 3 not found` | 没装或没加 PATH。装完**关掉命令行窗口再重开**（PATH 不会热更新） |
| `30 秒内调试端口仍未就绪` | ① 安全软件拦截本地端口 ② 企业策略禁用远程调试。先用浏览器访问 `http://127.0.0.1:9222/json/version` 确认 |
| `调试浏览器里没有登录态` | 在专用窗口里登录一次再重跑 |
| `列表页加载超时` | 网络慢或页面没打开。在专用窗口手动打开一次评教列表页再重跑 |
| 跑一半停了，提示「数量未减少」 | 页面可能报错或被挤下线。重新双击运行即可，已提交的会自动跳过 |
| 提示某门课「无可填表单，跳过」 | 这门已经评过了，正常现象 |
| 内容填错了 | 提交后改不了。下次运行按提示重新输入即可（已提交的不会重复提交） |

## 高级用法（不想用 bat）

已经有 9222 调试端口的话，可以跳过启动器直接跑执行器，用参数指定内容：

```bat
python run.py config.json --pick 较好 --fill 无 --fill 多讲案例 --fill 95
```

- `--pick`：选择题选项
- `--fill`：填空内容，按顺序重复传（三个空传三次）
- 都不传 = 用 `config.json` 里 `answer` 的默认值

适合自己写脚本封装，或让 AI Agent 接管。参数与退出码见上一层 `README.md`。
