# macOS · 使用说明

## 你需要准备

- macOS 12 或更新
- Google Chrome 或 Microsoft Edge（任选其一，装在 `/Applications` 下）
- Python 3（macOS 12.3 起系统不再自带，需要自己装）
  - 官网：https://www.python.org/downloads/macos/
  - 或 Homebrew：`brew install python`

检查是否已装：

```bash
python3 --version
```

## 第一次使用

### 1. 赋予执行权限（关键，只做一次）

从 Windows 传过来的文件会**丢掉可执行位**，直接双击会用文本编辑器打开。打开「终端」，执行：

```bash
cd ~/Downloads/评教自动化分发包/L2_命令行用户/macOS
chmod +x 一键评教.command
```

> 小技巧：在终端输入 `cd `（后面带空格），然后把 `macOS` 文件夹直接拖进终端窗口，路径会自动补全。

### 2. 双击 `一键评教.command`

首次可能提示「无法打开，因为来自身份不明的开发者」：

- 在文件上**右键** →「打开」→ 弹窗里再点「打开」（方式一）
- 或 系统设置 → 隐私与安全性 → 底部点「仍要打开」（方式二）

之后双击就不会再拦了。

### 3. 在弹出的浏览器窗口登录

- 脚本会在独立配置目录拉起 Chrome / Edge
- **首次需要登录一次**评教系统，能看到课程列表即可
- 登录态存在 `~/Library/Application Support/PJAuto/ChromeProfile`，以后不用再登
- 和你日常用的浏览器互不影响

### 4. 逐项回答要填什么

回到「终端」窗口，按提示输入（见下一节），最后确认 `Y`，就开始跑了。

## 终端会问你什么

样例（假设选「较好」、优点写「多讲案例」、打 95 分）：

```text
[2/4] 请设定要填写的内容（直接回车 = 用方括号里的默认值）

      选择题（1)好   2)较好   3)一般   4)较差   5)差）
      选哪一项？[1-5，回车=1 好]：2

      填空题共 3 项（按页面上的顺序）：
       1. 需要改进的地方？ [回车=无]：
       2. 突出优点是什么？ [回车=无]：多讲案例
       3. 打多少分？（满分100分） [回车=90]：95

[3/4] 将要提交的内容

      选择题：每题都选「较好」
      需要改进的地方？ 无
      突出优点是什么？ 多讲案例
      打多少分？（满分100分） 95

      评教一经提交无法修改，请再核对一遍。

      确认开始？输入 Y 回车开始，直接回车取消：Y
```

输入规则：

| 你想做的 | 怎么输 |
|---------|--------|
| 选某个选项 | 输编号 `1`–`5`，或直接输「好」「较好」「一般」「较差」「差」 |
| 用默认值 | 直接回车 |
| 填空留空 | 输一个 `-` |
| 改主意取消 | 在最后「确认开始」那一步直接回车 |
| 输错了 | 选择题会重问（最多 3 次，之后用默认）；填空只能重跑一次 |

两个细节：

- 全角数字会自动转成半角。
- 分数超出 0–100 或不是数字时，只**提醒**不拦你。

## 以后使用

双击 `一键评教.command` 即可。端口还开着就跳过启动，仍然会问内容并要你确认。

如果双击后终端一闪就关，说明还有报错——在终端里手动执行可以看到完整信息：

```bash
cd ~/Downloads/评教自动化分发包/L2_命令行用户/macOS
python3 launcher.py
```

## 常用操作

| 想做的事 | 怎么做 |
|---------|--------|
| 改这次填的内容 | 运行时按提示输入，**不用改任何文件** |
| 改「回车默认值」 | 文本编辑器打开 `config.json`，改 `answer` 段里的 `pick` 和 `fills` |
| 查看端口是否就绪 | 浏览器打开 `http://127.0.0.1:9222/json/version` |
| 彻底重置登录态 | 删除 `~/Library/Application Support/PJAuto` 目录 |
| 更换评教地址 | 改 `config.json` 的 `list_url` |

## 故障排查

| 现象 | 原因 / 解决 |
|------|------------|
| 双击用文本编辑器打开了 | 没有执行权限 → `chmod +x 一键评教.command` |
| 「来自身份不明的开发者」 | 右键 →「打开」；或系统设置里允许 |
| `没有找到 Python 3` | 装 Python 3（见上），装完重开终端 |
| `没找到 Chrome / Edge` | 把浏览器装到 `/Applications` 下；只支持 Chromium 系（Safari / Firefox 不行） |
| `30 秒内调试端口仍未就绪` | 浏览器企业策略禁用远程调试，或安全软件拦截。先访问 `http://127.0.0.1:9222/json/version` 自查 |
| `调试浏览器里没有登录态` | 在专用窗口里登录一次再重跑 |
| 终端窗口一闪而过 | 手动执行 `python3 launcher.py` 看完整报错 |
| 内容填错了 | 提交后改不了。下次运行重新输入即可（已提交的不会重复提交） |

## 高级用法（不想用 .command）

已经有 9222 调试端口时，可跳过启动器，用参数指定内容：

```bash
python3 run.py config.json --pick 较好 --fill 无 --fill 多讲案例 --fill 95
```

- `--pick`：选择题选项
- `--fill`：填空内容，按顺序重复传（三个空传三次）
- 都不传 = 用 `config.json` 里 `answer` 的默认值

macOS 上手动开调试端口：

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --remote-debugging-port=9222 \
  --user-data-dir="$HOME/Library/Application Support/PJAuto/ChromeProfile"
```

参数与退出码见上一层 `README.md`。
