# L3 · 小白版（书签）

不用装软件、不用敲命令，只需要会点鼠标。**Windows / macOS 都通用**，Edge、Chrome 都支持。

## 它是什么

一个「书签」，但它不是网址，而是一小段程序。点它的时候，它会在**当前网页**里按你事先设定的内容把评教表填好（并提交）。

因为是在网页内部操作，所以不需要安装任何东西，也不会有命令行窗口、端口、权限这些麻烦事。

## 安装（只做一次）

1. 双击 `一键安装评教书签.html`（会用默认浏览器打开）
2. 按 `Ctrl + Shift + B` 显示出书签栏
   - macOS 是 `Cmd + Shift + B`
3. 在页面**第二步**设定好你要填的内容（见下节），点 **「生成书签」**
4. 把页面上的蓝色按钮 **「一键评教」** 拖到书签栏里松开
   - 拖不动的话，页面第三步有备用办法：书签栏空白处右键 → 添加书签 → 把那一长串代码粘进去（旁边有「复制这段代码」按钮）

装好后，书签栏里就多了一个「一键评教」。

## 能设定什么

评教表固定是「若干道选择题（每题五个选项）+ 三个填空」，所以只要定这几件事：

| 设定项 | 说明 | 默认 |
|--------|------|------|
| 选择题选哪一项 | 五选一：好 / 较好 / 一般 / 较差 / 差。每题都选这一项 | `好` |
| 填空 1：需要改进的地方？ | 一行文字，不想写就留空 | `无` |
| 填空 2：突出优点是什么？ | 同上 | `无` |
| 填空 3：打多少分？（满分 100 分） | 0–100 的数字 | `90` |
| 填好后自动提交 | 勾选＝填完立刻提交；取消＝只填写，你自己检查完再点提交 | 勾选 |

两个细节：

- 三个空**按页面上的顺序**填：第一个空填「需要改进的地方」，第二个空填「突出优点」，第三个空填分数。
- 分数如果不是 0–100 的数字，页面会提醒你一次（只提醒，不阻止）。

## 第一次用，建议这样试

1. 把「填好后自动提交」**取消勾选**
2. 点「生成书签」，拖到书签栏
3. 进一门课，点书签 → 看它填的内容对不对
4. 确认没问题，再回来勾上自动提交、重新生成、重新拖一次

评教**一经提交无法修改**，花这一分钟值得。

## 使用方法（每门课重复）

1. 正常打开评教页面，**登录**
2. 在「待评教」列表里点某门课的 **「立即评价」**，进入填写页面
3. 点一下书签栏的 **「一键评教」**
4. 页面弹出提示（例如「已填写 12/12 题（选「好」），已提交」），然后自动回到列表
5. 回到第 2 步，处理下一门，直到「待评教」里没有课了

> 一学期如果有 10 门课，就是「点进课程 → 点书签」重复 10 次，大约 1 分钟。

## 改设定之后

改完任何一项，蓝色按钮会**变灰、拖不动**，提示「设置改过了，先点生成书签」。这是故意的，防止你把旧内容当新内容用。

正确做法：

1. 点 **「生成书签」**
2. 把**新的**蓝色按钮拖到书签栏
3. 拖到同名书签上会**覆盖**旧的，确认覆盖即可

已经拖出去的那个书签**不会自动更新**。要改内容，只能重新生成、重新拖。

## 安全说明

- 书签只在你**手动点击**并且**停留在评教填写页**时才动作，看一眼代码就能确认
- 它不会上传、不会记录、不会访问其他网站
- 所有设定都写在你拖的那个书签里，不存在任何上传或云端保存
- 想删掉：书签栏上右键 → 删除，就彻底没了

## 出问题怎么办

| 现象 | 怎么办 |
|------|--------|
| 点书签没反应 | 确认你停在**课程填写页**（能看到题目和「提交」按钮），不是列表页 |
| 提示「不是评教填写页」 | 先点进某门课的「立即评价」再点书签 |
| 提示「一道题都没选上，已停止提交」 | 页面上的选项文字和你选的不一致（可能改版了）。换一个选项试试，或找维护者更新 |
| 提示「没找到提交按钮」 | 页面可能没加载完，等两秒再点一次；或这门课的表单结构不一样，手动提交 |
| 蓝色按钮变灰拖不动 | 你改过设定还没生成。点「生成书签」 |
| 书签栏看不到 | `Ctrl + Shift + B`（macOS `Cmd + Shift + B`） |
| 拖不动书签 | 用第三步的备用办法：右键添加书签 + 粘贴代码 |
| 提示「您已填写，不可重复填写」 | 这门之前已经评过了，回列表处理下一门 |
| 三个空填串了位置 | 说明页面上的填空顺序和预期不同。这几项改手动填，别用书签 |

## 注意

- 只支持 **Edge / Chrome** 这类 Chromium 浏览器。**Safari 和 Firefox 不支持**书签里执行脚本（Safari 会直接丢弃 `javascript:` 书签）。
- 手机浏览器不支持，请用电脑。
- 如果之前装过旧版书签，**先删掉旧的再拖新的**，否则点的还是旧逻辑。
- 换电脑 / 换浏览器：把 `一键安装评教书签.html` 带过去，重新设定、重新拖一次（设定不会跟着书签跨浏览器迁移）。

## 为什么这版最适合「什么都不懂」的人

| 对比 | L3 书签 | L2 命令行 |
|------|---------|-----------|
| 要装 Python | 不用 | 要 |
| 会出现黑色命令行窗口 | 不会 | 会 |
| 要理解端口、路径、权限 | 不用 | 要 |
| 能自己改填写内容 | 页面上点一点就行 | 命令行里按提示输入 |
| 换电脑 | 重新拖一次书签 | 装 Python + 重新登录 |
| 每门课操作 | 2 次点击 | 全自动 |

代价是要一门一门点。课不多的话，这个反而最省心。
