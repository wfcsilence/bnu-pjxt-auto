# 浏览器表单自动化

用 CDP 在**用户已登录**的浏览器里执行 JS，按配方循环完成表单。引擎零第三方依赖（纯 Python 标准库）。

## 必须先问用户，再动手

填什么由用户决定，**不要拿默认值直接跑**。运行前把下面四项一次问完（不要分多轮）：

1. **选择题每题都选哪一项？** 好 / 较好 / 一般 / 较差 / 差（默认「好」）
2. **「需要改进的地方？」填什么？**（默认「无」）
3. **「突出优点是什么？」填什么？**（默认「无」）
4. **「打多少分？（满分100分）」填多少？**（默认「90」，0–100 的数字）

提问可以直接这样写：

> 开始前确认一下要填的内容（评教提交后不能修改）：
> 1. 选择题每题都选哪一项？好 / 较好 / 一般 / 较差 / 差（默认：好）
> 2. 需要改进的地方？（默认：无）
> 3. 突出优点是什么？（默认：无）
> 4. 打多少分？满分 100，填数字（默认：90）
>
> 直接说「用默认」也可以。

拿到回答后，**先用一句话复述「选项 + 三个填空」，再执行**，让用户有机会纠正。

只有两种情况可以跳过提问：

- 用户在同一条消息里已经明确给出了这四项内容；
- 用户明确说「都用默认」「随便填」。

## 前置条件

浏览器必须以调试端口启动，且已登录目标站点：

```
msedge.exe --remote-debugging-port=9222 --user-data-dir="%LOCALAPPDATA%\PJAuto\EdgeProfile"
```

Chrome 换成 `chrome.exe`。

**必须用独立专用目录（不要指向上面的默认 User Data）**：新版 Chromium 系浏览器会拒绝在默认配置目录上开启调试端口，端口会一直起不来。独立目录的代价是首次需要在该窗口登录一次，之后登录态长期保留，且不影响用户平时用的浏览器窗口。

用 Python 判断端口是否就绪：`socket.connect_ex(("127.0.0.1", 9222)) == 0`。未就绪时按上面的命令启动，轮询等待（通常 2–3 秒），不要用固定 sleep。

## 执行流程

1. **先问清要填的内容**（见上一节），问清后再往下走。
2. 确认浏览器已用调试端口启动并登录，手动打开目标列表页。
3. 选择配方：用户给了配方就用；否则读 `recipes/` 下现成的；新站点参考 `recipes/bnu-pjxt.json` 生成一份（见下）。
4. 运行，并把用户的回答作为参数传进去：

```bash
python scripts/run.py recipes/bnu-pjxt.json --pick 好 --fill 无 --fill 无 --fill 90
```

`--pick` 覆盖选择题选项，`--fill` 按顺序重复传（三个空就传三次）；不传则用配方 `answer` 里的默认值。

5. 读取输出，向用户报告「填写了什么 + 提交数量 + 跳过项」。

## 配方格式

配方是 JSON，关键字段：

- `site_key`：URL 中用于定位页面的子串
- `list_url`：列表页地址，每轮回到这里
- `answer`：默认填写内容 —— `pick`（选项）、`pick_options`（可选清单，供提问用）、`fills`（`label` + `default` 的数组，顺序即页面上的填空顺序）
- `js.list`：返回 `{n: 待办数, names: [名称]}`
- `js.click`：点击第 `__INDEX__` 个待办（占位符会被替换）
- `js.check`：返回 `{forms: 表单数}`，为 0 表示无可填项
- `js.ready`：返回 `{hasList, login}`，执行器据此区分「未登录」与「加载慢」，缺失则跳过检查
- `js.fill_submit`：一次性填完并提交当前表单。里面的 `__PICK__` / `__FILLS__` 会被替换成 `--pick` / `--fill` 传入的值（JSON 字面量），不要自己写死选项文字
- `wait_after_*_sec`：各步骤等待秒数

`recipes/bnu-pjxt.json` 是完整可运行范例。新站点只需复制后改 JS 与 URL，不要动 `scripts/`。

## 注意事项

- 提交后页面会跳转，所以成功与否用「待办数量是否减少」判断，不要依赖 JS 回传。
- 覆盖原生确认框用 `window.confirm = function(){ return true; };`，避免处理弹窗。
- 遇到「已填写」页（`forms=0`），执行器会自动跳过该教师并回列表。
- 不要用固定坐标或截图定位——CDP 下所有操作都在页面上下文完成。
- 若浏览器未启动或找不到页面，`engine.py` 会给出明确错误，按提示重启浏览器即可。
